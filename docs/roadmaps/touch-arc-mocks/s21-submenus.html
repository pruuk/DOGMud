Contextual menus three levels deep (Galaxy S21 deck, 1:1)

Each step is a crop of the S21 screen: the last lines of game text, the deck, and the command box. Every button is brass (brand rule); kinds differ by shape and edge. A level replaces the whole deck. Back is always top-left and names where it goes; More is always bottom-right and only appears when the list does not fit. Inside a level, the same item keeps the same slot every time. The ◢ mark means the button opens a deeper level (or does more on a long press). Lists show only what you know, real names from the game data.
